**Scene 2: GitHub’s Canvases — Beyond chat to full-stack apps**  
**Narration:**  
GitHub introduced something called “canvases” inside the Copilot app. A canvas is like a mini full-stack app that runs inside the Copilot environment. It lets the AI and you communicate back and forth, not just by typing messages but by interacting with a real interface.  
This means you can build tools where the AI controls parts of the app, and you can click or type in others. For example, you could play a Connect 4 game with the AI inside the app or manage software packages with a graphical interface.  
This is a big step beyond just typing prompts in a chat box. It lets you automate workflows and take yourself out of the loop for many steps.

**Scene 3: Tailoring AI to your codebase with custom instructions and agents**  
**Narration:**  
GitHub also added ways to teach Copilot about your project’s rules and workflows. You can add custom instructions that tell Copilot how your codebase is structured and what conventions to follow.  
You can package repeatable tasks as “agent skills” and create “custom agents” specialized for bigger tasks. Plus, you can connect Copilot to external tools using MCP servers, like running browser tests automatically.  
This means the AI understands your project better and can help more effectively, saving you time and reducing mistakes.

Diagram showing: Custom instructions → Agent skills → Custom agents → MCP servers

**Scene 4: OpenAI’s Computer Use agents — AI with its own Linux computer**  
**Narration:**  
OpenAI announced “Computer Use” agents that run on personal Linux virtual computers in the cloud. These agents can use full desktop apps and web browsers just like you do.  
For example, one user saved two hours by letting the agent place a complicated meal prep order online. The agent did it eight times faster than the user could.  
This shows AI agents are becoming more autonomous and can handle complex, multi-step tasks on your behalf.

**Scene 5: Voice-driven coding demo — building by talking**  
**Narration:**  
Simon Willison demonstrated building a new blog feature almost entirely by voice using Codex in a local development environment.  
He talked to his laptop while cooking dinner, and the AI wrote code, asked clarifying questions, and showed previews. After about 30 minutes, they had a working feature ready for review.  
This shows how voice-driven workflows can help multitask and speed up development, especially for simple, well-understood features.

**Scene 6: What this means for learners — delegate more, but review carefully**  
**Narration:**  
With these new tools, learners can delegate more complex, multi-step tasks to AI agents. You spend less time typing every line and more time defining what you want, reviewing the AI’s output, and making decisions.  
But remember, you’re still responsible for the final code. AI can speed up implementation, but you must check correctness, security, and fit with your project.  
Learning to direct AI agents well is becoming a key skill.
