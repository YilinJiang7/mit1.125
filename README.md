Each problem set folder is self-contained: the scripts that produce the data, the
dataset itself, the published site, and a README explaining how to reproduce every
number.

Every site is a single self-contained HTML file — no server, no build step, no network
calls at run time — so `psetN/site/index.html` opens by double-clicking it.

## Repository layout

```
index.html               Sends the Pages root straight to the newest problem set
pset1/                   Problem Set 01 — road safety priorities
├── README.md            What it does, how to reproduce it, the data sources
├── scripts/
│   ├── fetch_crashes.py     1. download from MassDOT, with row-count verification
│   ├── slim_data.py         2. 124 columns -> the 57 used
│   ├── clean_and_score.py   3. clean, cluster at 25 m, EPDO score, verify vs MassDOT
│   └── build_site_data.py   4. field dictionary + payload + inline into the page
├── data/                Everything the scripts generate. Not committed.
│   ├── raw/                 the MassDOT download, ~120 MB
│   ├── slim/                the kept columns, gzipped
│   ├── out/                 cleaned dataset + aggregates
│   └── build/               data.json + basemap.png
└── site/
    ├── _template.html   the page source, before the data is inlined into it
    ├── index.html       the published page, fully self-contained
    └── data/            the collected dataset, zipped — this is the deliverable

example-dataset/         The energy CSV from Lecture 03, kept for reference
```

Raw downloads and analysis outputs are not committed — they are regenerated by the
scripts. See each problem set's README for the exact commands.
