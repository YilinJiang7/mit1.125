## Problem sets

| # | Title | What it is | Live | Code |
|---|---|---|---|---|
| 01 | **Where to Fix the Streets First** | A crash-prioritisation tool for Boston, Cambridge and Somerville, built on 37,929 MassDOT crash records from 2021–2025 | [Live site](https://street-risk-boston-cambridge-somerville.yilin-jiang.chatgpt.site/) · [GitHub Pages mirror](https://yilinjiang7.github.io/mit1.125/pset1/site/) | [`pset1/`](pset1/) |
| 02 | **Book Manager** | A personal command-line book manager in small Bash programs + Gum: library, metadata lookup, reading goal & takeaways, and three recommendation agents run in parallel and refined through pipes | run `./app.sh` (terminal app) | [`pset2/book-manager/`](pset2/book-manager/) |

**PSet 01 demo video:** [Five-minute walkthrough](https://youtu.be/YL_1ogZsPz0)

**PSet 02 demo video:** [YouTube](https://youtu.be/w0VZXkEsENc) · [pset2/book-manager/mit1.125-pset2-YilinJiang.mov](pset2/book-manager/mit1.125-pset2-YilinJiang.mov)

Each problem set folder is self-contained: the scripts that produce the data, the
dataset itself, the published site, and a README explaining how to reproduce every
number.

PSet 01's site is a single self-contained HTML file — no server, no build step, no network
calls at run time — so `psetN/site/index.html` opens by double-clicking it.

## Repository layout

```
pset1/                   Problem Set 01 — road safety priorities
├── README.md            What it does, how to reproduce it, the data sources
├── scripts/
│   ├── fetch_crashes.py     1. download from MassDOT, with row-count verification
│   ├── slim_data.py         2. 124 columns -> the 57 used
│   ├── clean_and_score.py   3. clean, cluster at 25 m, EPDO score, verify vs MassDOT
│   └── build_site_data.py   4. field dictionary + payload + inline into the page
├── data/                Everything the scripts generate. Not committed.
│   ├── raw/                 the MassDOT download, ~120 MB
│   ├── slim/                the kept columns, gzipped
│   ├── out/                 cleaned dataset + aggregates
│   └── build/               data.json + basemap.png
└── site/
    ├── _template.html   the page source, before the data is inlined into it
    ├── index.html       the published page, fully self-contained
    └── data/            the collected dataset, zipped — this is the deliverable
pset2/                   Problem Set 02 — personal Book Manager (Bash + Gum)
└── book-manager/
    ├── app.sh               entry point: main menu → workflows
    ├── ui/                  Gum screens (menu, library, recommendations)
    ├── workflows/           manage_library.sh, get_recommendations.sh (parallel agents)
    ├── books/               metadata lookup, library search
    ├── recommendations/     history / interests / discovery agents + refine
    ├── data/                book_database.sh — the only file that touches books.csv
    ├── tests/smoke_test.sh  quick self-checks
    └── mit1.125-pset2-YilinJiang.mov   narrated demo video (480p)
```

Raw downloads and analysis outputs are not committed — they are regenerated by the
scripts. See each problem set's README for the exact commands.
